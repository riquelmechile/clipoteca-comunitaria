# Seguridad

## Versiones soportadas

La serie 3.1.x recibe correcciones de seguridad. Las versiones anteriores no
estan soportadas.

## Reportar una vulnerabilidad

Usa un GitHub Security Advisory privado del repositorio: abre **Security** y
selecciona **Report a vulnerability**. No publiques detalles de la
vulnerabilidad en un issue.

Confirmaremos la recepcion dentro de 7 dias. El proyecto no ofrece recompensa
economica.

## Alcance

El alcance incluye el Worker REST/MCP, los workflows y el pipeline. Quedan
fuera de alcance el contenido de clips de terceros y las cuotas que forman
parte del diseno documentado del servicio.
